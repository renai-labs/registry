longDescription: "Five projects share one flow. Plan turns a Slack message or a
  Linear issue into an implementation plan you approve. Build writes the code
  and opens a draft pull request. Review reads it on a different model and
  leaves its findings on GitHub. QA runs the change and a browser in a sandbox
  and marks the pull request ready when it holds up. You merge. Overnight,
  Monitoring keeps the docs in step with what shipped and consolidates what the
  factory learned, and every four hours it checks what recent releases did to
  production. You decide twice: the plan, and the merge."
